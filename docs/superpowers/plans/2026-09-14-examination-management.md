# Phase 5 — Examination Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add exam types, exams, exam schedules, marks entry (with assignment-based teacher authorization), a completion overview, and a real student-profile Results tab to the existing School Management System, for Classes 1–10.

**Architecture:** Four additive Prisma models (`ExamType`, `Exam`, `ExamSchedule`, `ExamMark`) layered on the existing School/AcademicYear/Class/Section/Subject/ClassSubject/TeacherAssignment/Student foundation. Every new route, action, and component copies an existing analog verbatim in structure — the `academics/*` CRUD pages for Exam Types/Exams/Schedules, and `attendance/*` for the marks-entry workflow and its per-request teacher-authorization re-check.

**Tech Stack:** Next.js 16 App Router, React 19 Server Components + Server Actions, Prisma 7 (`@prisma/adapter-pg`) + PostgreSQL (Neon), Zod 4, React Hook Form + `@hookform/resolvers/zod`, existing shadcn/`@base-ui` component set, `next-intl` (cookie-based locale, no `[locale]` route segment), `iron-session` DAL.

**Spec:** `docs/superpowers/specs/2026-09-14-examination-management-design.md` — read it alongside this plan; this plan argues from that spec and does not repeat its rationale.

## Global Constraints

- Reuse existing models (`School`, `User`, `AcademicYear`, `Class`, `Section`, `Subject`, `ClassSubject`, `TeacherAssignment`, `Student`, `Attendance`) — do not duplicate academic/class/section/subject/teacher structures.
- Strict scope: exam types, exams, exam schedules, marks configuration, marks entry, teacher marks-entry authorization, a basic completion overview, and student-profile Results integration. Nothing else (no report cards, GPA/ranking, promotion, fees, homework, timetable, notifications, portals, bulk import, NCTB grading, analytics dashboards).
- Every school-owned Prisma model carries `schoolId` + `@@index([schoolId])`; ids are `cuid()`; `isActive` is the soft-deactivation flag; table names are `@@map`-ed snake_case plural; every new model gets a short rationale comment matching existing style.
- Every server action: `"use server"` file-level, `requireRole(...)` first line, `getTranslations(...)` for user-facing strings, Zod `safeParse` (never `parse`), ownership re-validation via `findFirst` scoped to `user.schoolId`, `prisma-errors.ts` helpers for P2002, `revalidatePath(...)`, return `{}`/`{ ...data }` on success or `{ error }` on failure — never throw for expected/validation failures.
- Every client ID (query param, route param, form field) is re-validated server-side against the database scoped to `user.schoolId` before use. Never trust an ID because it appeared in the UI.
- Teacher marks entry requires `TeacherAssignment(teacherId, classId, sectionId, subjectId)` to match exactly; this is re-checked in the server action regardless of what the client submitted. Admin/Principal bypass this specific check but are still scoped to `user.schoolId`.
- No new runtime dependencies (Redis, GraphQL, REST CRUD APIs, microservices, queues, state-management libraries, new UI kit). `playwright` is added as a **devDependency only**, for the browser verification the phase brief explicitly requires (Task 12) — it never ships in the app bundle.
- No DataTable abstraction — hand-roll `<Table>` per list page, matching every existing list page.
- All user-facing text goes through `next-intl` (`useTranslations` client / `getTranslations` server) with both English and Bangla strings added in the same task as the keys are introduced.
- This codebase has **no unit test runner** (no jest/vitest anywhere in `package.json` or the tree) and **zero existing test files** — every existing module (`academics`, `students`, `attendance`) ships with no automated tests, verified instead by `npm run lint` + `npm run build` + manual/browser QA. This plan follows that existing convention rather than introducing a new per-file test framework: each task's "test" step is `npx tsc --noEmit` (typecheck) run against the whole project, not a red/green unit test. Real functional verification happens once, end-to-end, in Task 12 via a Playwright script against the actual Neon database — this is the adaptation of TDD's red/green cycle to a codebase that has never had one.

```prisma
// A school-defined kind of exam (Class Test, Half-Yearly, Final Exam, ...).
// Not an enum: schools must be able to name their own exam types.
model ExamType {
  id        String   @id @default(cuid())
  schoolId  String
  name      String
  nameBn    String?
  isActive  Boolean  @default(true)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  school School @relation(fields: [schoolId], references: [id])
  exams  Exam[]

  @@unique([schoolId, name])
  @@index([schoolId])
  @@map("exam_types")
}

// One sitting of an ExamType in a given academic year (e.g. "First Term
// Class Test, 2026"). Which subjects/classes it covers is the separate
// ExamSchedule relationship below, mirroring how Subject/ClassSubject work.
model Exam {
  id             String   @id @default(cuid())
  schoolId       String
  academicYearId String
  examTypeId     String
  name           String
  nameBn         String?
  startDate      DateTime @db.Date
  endDate        DateTime @db.Date
  isActive       Boolean  @default(true)
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt

  school       School         @relation(fields: [schoolId], references: [id])
  academicYear AcademicYear   @relation(fields: [academicYearId], references: [id])
  examType     ExamType       @relation(fields: [examTypeId], references: [id])
  schedules    ExamSchedule[]

  @@index([schoolId])
  @@index([schoolId, academicYearId])
  @@map("exams")
}

// One subject scheduled for one class within an exam (the whole class, not
// a single section — a class's sections all sit the same paper on the same
// date with the same full/pass marks). Class → Subject is constrained to
// ClassSubject at the application layer, the same rule TeacherAssignment
// already follows.
model ExamSchedule {
  id        String    @id @default(cuid())
  schoolId  String
  examId    String
  classId   String
  subjectId String
  examDate  DateTime  @db.Date
  startTime DateTime? @db.Time
  endTime   DateTime? @db.Time
  room      String?
  fullMarks Int
  passMarks Int
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt

  school  School     @relation(fields: [schoolId], references: [id])
  exam    Exam       @relation(fields: [examId], references: [id])
  class   Class      @relation(fields: [classId], references: [id])
  subject Subject    @relation(fields: [subjectId], references: [id])
  marks   ExamMark[]

  @@unique([examId, classId, subjectId])
  @@index([schoolId])
  @@index([classId, subjectId])
  @@map("exam_schedules")
}

// One student's result for one ExamSchedule. `marks` is null exactly when
// `isAbsent` is true; no calculated grade/GPA is stored here (Phase 5 makes
// no assumption about the school's grading scale).
model ExamMark {
  id             String   @id @default(cuid())
  schoolId       String
  examScheduleId String
  studentId      String
  marks          Float?
  isAbsent       Boolean  @default(false)
  enteredById    String
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt

  school       School       @relation(fields: [schoolId], references: [id])
  examSchedule ExamSchedule @relation(fields: [examScheduleId], references: [id], onDelete: Cascade)
  student      Student      @relation(fields: [studentId], references: [id], onDelete: Cascade)
  enteredBy    User         @relation("ExamMarksEntered", fields: [enteredById], references: [id])

  @@unique([examScheduleId, studentId])
  @@index([schoolId])
  @@index([studentId])
  @@map("exam_marks")
}
```

- [ ] **Step 1: Write the schema file**

```typescript
import { z } from "zod"

// Error messages are i18n keys relative to the "exams" namespace, same
// convention as lib/validations/academics.ts and lib/validations/attendance.ts.
const errors = {
  nameRequired: "errors.nameRequired",
  academicYearRequired: "errors.academicYearRequired",
  examTypeRequired: "errors.examTypeRequired",
  invalidDateRange: "errors.invalidDateRange",
  classRequired: "errors.classRequired",
  subjectRequired: "errors.subjectRequired",
  fullMarksInvalid: "errors.fullMarksInvalid",
  passMarksInvalid: "errors.passMarksInvalid",
  invalidTimeRange: "errors.invalidTimeRange",
  marksRequired: "errors.marksOutOfRange",
  marksMustBeNull: "errors.marksOutOfRange",
}

const TIME_PATTERN = /^([01]\d|2[0-3]):[0-5]\d$/

export const createExamTypeSchema = z.object({
  name: z.string().trim().min(1, { error: errors.nameRequired }),
  nameBn: z.string().trim().optional().or(z.literal("")),
})
export type CreateExamTypeInput = z.infer<typeof createExamTypeSchema>

export const editExamTypeSchema = z.object({
  id: z.string().min(1),
  name: z.string().trim().min(1, { error: errors.nameRequired }),
  nameBn: z.string().trim().optional().or(z.literal("")),
  isActive: z.boolean(),
})
export type EditExamTypeInput = z.infer<typeof editExamTypeSchema>

const examDateFields = {
  name: z.string().trim().min(1, { error: errors.nameRequired }),
  nameBn: z.string().trim().optional().or(z.literal("")),
  academicYearId: z.string().min(1, { error: errors.academicYearRequired }),
  examTypeId: z.string().min(1, { error: errors.examTypeRequired }),
  startDate: z.string().refine((value) => !Number.isNaN(Date.parse(value))),
  endDate: z.string().refine((value) => !Number.isNaN(Date.parse(value))),
}

export const createExamSchema = z
  .object(examDateFields)
  .refine((value) => value.startDate <= value.endDate, {
    error: errors.invalidDateRange,
    path: ["endDate"],
  })
export type CreateExamInput = z.infer<typeof createExamSchema>

export const editExamSchema = z
  .object({ id: z.string().min(1), isActive: z.boolean(), ...examDateFields })
  .refine((value) => value.startDate <= value.endDate, {
    error: errors.invalidDateRange,
    path: ["endDate"],
  })
export type EditExamInput = z.infer<typeof editExamSchema>

const examScheduleFields = {
  classId: z.string().min(1, { error: errors.classRequired }),
  subjectId: z.string().min(1, { error: errors.subjectRequired }),
  examDate: z.string().refine((value) => !Number.isNaN(Date.parse(value))),
  startTime: z
    .string()
    .regex(TIME_PATTERN)
    .optional()
    .or(z.literal("")),
  endTime: z
    .string()
    .regex(TIME_PATTERN)
    .optional()
    .or(z.literal("")),
  room: z.string().trim().optional().or(z.literal("")),
  fullMarks: z.coerce.number({ error: errors.fullMarksInvalid }).int().positive({ error: errors.fullMarksInvalid }),
  passMarks: z.coerce.number({ error: errors.passMarksInvalid }).int().min(0, { error: errors.passMarksInvalid }),
}

function refineSchedule<T extends z.ZodRawShape>(schema: z.ZodObject<T>) {
  return schema
    .refine((value) => value.passMarks <= value.fullMarks, {
      error: errors.passMarksInvalid,
      path: ["passMarks"],
    })
    .refine((value) => !value.startTime || !value.endTime || value.endTime > value.startTime, {
      error: errors.invalidTimeRange,
      path: ["endTime"],
    })
}

export const createExamScheduleSchema = refineSchedule(
  z.object({ examId: z.string().min(1), ...examScheduleFields })
)
export type CreateExamScheduleInput = z.infer<typeof createExamScheduleSchema>

export const editExamScheduleSchema = refineSchedule(
  z.object({ id: z.string().min(1), examId: z.string().min(1), ...examScheduleFields })
)
export type EditExamScheduleInput = z.infer<typeof editExamScheduleSchema>

const examMarkEntrySchema = z
  .object({
    studentId: z.string().min(1),
    marks: z.number().min(0).nullable(),
    isAbsent: z.boolean(),
  })
  .refine((value) => (value.isAbsent ? value.marks === null : value.marks !== null), {
    error: errors.marksRequired,
    path: ["marks"],
  })

export const saveExamMarksSchema = z.object({
  examScheduleId: z.string().min(1),
  sectionId: z.string().min(1),
  entries: z.array(examMarkEntrySchema).min(1),
})
export type SaveExamMarksInput = z.infer<typeof saveExamMarksSchema>
```

- [ ] **Step 2: Write the completion helper**

```typescript
import "server-only"
import { prisma } from "@/lib/db/client"

// Shared by the exam detail page (whole-class completion, no section
// filter) and the marks-entry page (scoped to the section being entered).
// Counts marks by joining back through `student` rather than trusting a
// denormalized section on ExamMark (there isn't one — see the design spec's
// rationale for keeping ExamMark exactly as specified), so a completion
// count for one section never includes another section's rows.
export async function getScheduleCompletion({
  scheduleId,
  schoolId,
  sectionId,
}: {
  scheduleId: string
  schoolId: string
  sectionId?: string
}): Promise<{ total: number; entered: number; absent: number; pending: number }> {
  const schedule = await prisma.examSchedule.findFirst({
    where: { id: scheduleId, schoolId },
    select: { classId: true, exam: { select: { academicYearId: true } } },
  })
  if (!schedule) {
    return { total: 0, entered: 0, absent: 0, pending: 0 }
  }

  const studentWhere = {
    schoolId,
    classId: schedule.classId,
    academicYearId: schedule.exam.academicYearId,
    status: "ACTIVE" as const,
    ...(sectionId && { sectionId }),
  }

  const [total, marks] = await Promise.all([
    prisma.student.count({ where: studentWhere }),
    prisma.examMark.findMany({
      where: { examScheduleId: scheduleId, student: studentWhere },
      select: { isAbsent: true },
    }),
  ])

  const absent = marks.filter((mark) => mark.isAbsent).length
  const entered = marks.length - absent
  return { total, entered, absent, pending: Math.max(0, total - marks.length) }
}
```

```typescript
export function parseTimeInput(value?: string | null): Date | null {
  if (!value) return null
  return new Date(`1970-01-01T${value}:00.000Z`)
}
```

```typescript
"use server"

import { revalidatePath } from "next/cache"
import { getTranslations } from "next-intl/server"
import { Role } from "@prisma/client"
import { prisma } from "@/lib/db/client"
import { requireRole } from "@/lib/auth/dal"
import { isUniqueConstraintError, uniqueConstraintTouches } from "@/lib/db/prisma-errors"
import {
  createExamTypeSchema,
  editExamTypeSchema,
  type CreateExamTypeInput,
  type EditExamTypeInput,
} from "@/lib/validations/exams"

const CAN_MANAGE: Role[] = [Role.SUPER_ADMIN, Role.SCHOOL_ADMIN, Role.PRINCIPAL]

export type ExamResult = { error?: string }

export async function createExamType(input: CreateExamTypeInput): Promise<ExamResult> {
  const user = await requireRole(...CAN_MANAGE)
  const t = await getTranslations("exams")

  const parsed = createExamTypeSchema.safeParse(input)
  if (!parsed.success) return { error: t("errors.invalidForm") }

  try {
    await prisma.examType.create({
      data: { schoolId: user.schoolId, name: parsed.data.name, nameBn: parsed.data.nameBn || null },
    })
  } catch (error) {
    if (isUniqueConstraintError(error)) return { error: t("errors.duplicateExamType") }
    return { error: t("errors.saveFailed") }
  }

  revalidatePath("/exams/types")
  return {}
}

export async function updateExamType(input: EditExamTypeInput): Promise<ExamResult> {
  const user = await requireRole(...CAN_MANAGE)
  const t = await getTranslations("exams")

  const parsed = editExamTypeSchema.safeParse(input)
  if (!parsed.success) return { error: t("errors.invalidForm") }

  const existing = await prisma.examType.findFirst({
    where: { id: parsed.data.id, schoolId: user.schoolId },
  })
  if (!existing) return { error: t("errors.notFound") }

  try {
    await prisma.examType.update({
      where: { id: parsed.data.id },
      data: { name: parsed.data.name, nameBn: parsed.data.nameBn || null, isActive: parsed.data.isActive },
    })
  } catch (error) {
    if (isUniqueConstraintError(error) && uniqueConstraintTouches(error, "name")) {
      return { error: t("errors.duplicateExamType") }
    }
    return { error: t("errors.saveFailed") }
  }

  revalidatePath("/exams/types")
  return {}
}
```

```typescript
"use server"

import { revalidatePath } from "next/cache"
import { getTranslations } from "next-intl/server"
import { Role } from "@prisma/client"
import { prisma } from "@/lib/db/client"
import { requireRole } from "@/lib/auth/dal"
import { createExamSchema, editExamSchema, type CreateExamInput, type EditExamInput } from "@/lib/validations/exams"

const CAN_MANAGE: Role[] = [Role.SUPER_ADMIN, Role.SCHOOL_ADMIN, Role.PRINCIPAL]

export type ExamResult = { error?: string }

async function validateAcademicSelection(schoolId: string, academicYearId: string, examTypeId: string) {
  const [academicYear, examType] = await Promise.all([
    prisma.academicYear.findFirst({ where: { id: academicYearId, schoolId } }),
    prisma.examType.findFirst({ where: { id: examTypeId, schoolId } }),
  ])
  return Boolean(academicYear && examType)
}

export async function createExam(input: CreateExamInput): Promise<ExamResult> {
  const user = await requireRole(...CAN_MANAGE)
  const t = await getTranslations("exams")

  const parsed = createExamSchema.safeParse(input)
  if (!parsed.success) return { error: t("errors.invalidForm") }
  const data = parsed.data

  const isValidSelection = await validateAcademicSelection(user.schoolId, data.academicYearId, data.examTypeId)
  if (!isValidSelection) return { error: t("errors.invalidAcademicSelection") }

  try {
    await prisma.exam.create({
      data: {
        schoolId: user.schoolId,
        academicYearId: data.academicYearId,
        examTypeId: data.examTypeId,
        name: data.name,
        nameBn: data.nameBn || null,
        startDate: new Date(data.startDate),
        endDate: new Date(data.endDate),
      },
    })
  } catch {
    return { error: t("errors.saveFailed") }
  }

  revalidatePath("/exams")
  return {}
}

export async function updateExam(input: EditExamInput): Promise<ExamResult> {
  const user = await requireRole(...CAN_MANAGE)
  const t = await getTranslations("exams")

  const parsed = editExamSchema.safeParse(input)
  if (!parsed.success) return { error: t("errors.invalidForm") }
  const data = parsed.data

  const existing = await prisma.exam.findFirst({ where: { id: data.id, schoolId: user.schoolId } })
  if (!existing) return { error: t("errors.notFound") }

  const isValidSelection = await validateAcademicSelection(user.schoolId, data.academicYearId, data.examTypeId)
  if (!isValidSelection) return { error: t("errors.invalidAcademicSelection") }

  try {
    await prisma.exam.update({
      where: { id: data.id },
      data: {
        academicYearId: data.academicYearId,
        examTypeId: data.examTypeId,
        name: data.name,
        nameBn: data.nameBn || null,
        startDate: new Date(data.startDate),
        endDate: new Date(data.endDate),
        isActive: data.isActive,
      },
    })
  } catch {
    return { error: t("errors.saveFailed") }
  }

  revalidatePath("/exams")
  revalidatePath(`/exams/${data.id}`)
  return {}
}
```

```typescript
function ExamFiltersInner({ academicYears, examTypes }: { academicYears: Option[]; examTypes: Option[] }) {
  const t = useTranslations("exams")
  const router = useRouter()
  const pathname = usePathname()
  const searchParams = useSearchParams()
  const formRef = useRef<HTMLFormElement>(null)

  function submit(overrides: Record<string, string> = {}) {
    const params = new URLSearchParams()
    const formData = new FormData(formRef.current!)

    for (const [key, value] of formData.entries()) {
      if (typeof value === "string" && value) params.set(key, value)
    }
    for (const [key, value] of Object.entries(overrides)) {
      if (value) params.set(key, value)
      else params.delete(key)
    }

    router.push(params.toString() ? `${pathname}?${params.toString()}` : pathname)
  }

  return (
    <form
      ref={formRef}
      onSubmit={(event) => {
        event.preventDefault()
        submit()
      }}
      className="flex flex-col gap-3 sm:flex-row sm:flex-wrap sm:items-center"
    >
```

```typescript
"use server"

import { revalidatePath } from "next/cache"
import { getTranslations } from "next-intl/server"
import { Role } from "@prisma/client"
import { prisma } from "@/lib/db/client"
import { requireRole } from "@/lib/auth/dal"
import { isUniqueConstraintError } from "@/lib/db/prisma-errors"
import { parseTimeInput } from "@/lib/exams/schedule-time"
import {
  createExamScheduleSchema,
  editExamScheduleSchema,
  type CreateExamScheduleInput,
  type EditExamScheduleInput,
} from "@/lib/validations/exams"

const CAN_MANAGE: Role[] = [Role.SUPER_ADMIN, Role.SCHOOL_ADMIN, Role.PRINCIPAL]

export type ExamResult = { error?: string }

async function validateClassSubject(schoolId: string, classId: string, subjectId: string) {
  const [klass, subject, classSubject] = await Promise.all([
    prisma.class.findFirst({ where: { id: classId, schoolId } }),
    prisma.subject.findFirst({ where: { id: subjectId, schoolId } }),
    prisma.classSubject.findFirst({ where: { classId, subjectId } }),
  ])
  if (!klass || !subject) return "invalidSelection" as const
  if (!classSubject) return "subjectNotInClass" as const
  return null
}

export async function createExamSchedule(input: CreateExamScheduleInput): Promise<ExamResult> {
  const user = await requireRole(...CAN_MANAGE)
  const t = await getTranslations("exams")

  const parsed = createExamScheduleSchema.safeParse(input)
  if (!parsed.success) return { error: t("errors.invalidForm") }
  const data = parsed.data

  const exam = await prisma.exam.findFirst({ where: { id: data.examId, schoolId: user.schoolId } })
  if (!exam) return { error: t("errors.notFound") }

  const validationError = await validateClassSubject(user.schoolId, data.classId, data.subjectId)
  if (validationError) return { error: t(`errors.${validationError}`) }

  try {
    await prisma.examSchedule.create({
      data: {
        schoolId: user.schoolId,
        examId: data.examId,
        classId: data.classId,
        subjectId: data.subjectId,
        examDate: new Date(data.examDate),
        startTime: parseTimeInput(data.startTime),
        endTime: parseTimeInput(data.endTime),
        room: data.room || null,
        fullMarks: data.fullMarks,
        passMarks: data.passMarks,
      },
    })
  } catch (error) {
    if (isUniqueConstraintError(error)) return { error: t("errors.duplicateSchedule") }
    return { error: t("errors.saveFailed") }
  }

  revalidatePath(`/exams/${data.examId}`)
  return {}
}

export async function updateExamSchedule(input: EditExamScheduleInput): Promise<ExamResult> {
  const user = await requireRole(...CAN_MANAGE)
  const t = await getTranslations("exams")

  const parsed = editExamScheduleSchema.safeParse(input)
  if (!parsed.success) return { error: t("errors.invalidForm") }
  const data = parsed.data

  const existing = await prisma.examSchedule.findFirst({ where: { id: data.id, schoolId: user.schoolId } })
  if (!existing) return { error: t("errors.notFound") }

  const validationError = await validateClassSubject(user.schoolId, data.classId, data.subjectId)
  if (validationError) return { error: t(`errors.${validationError}`) }

  try {
    await prisma.examSchedule.update({
      where: { id: data.id },
      data: {
        classId: data.classId,
        subjectId: data.subjectId,
        examDate: new Date(data.examDate),
        startTime: parseTimeInput(data.startTime),
        endTime: parseTimeInput(data.endTime),
        room: data.room || null,
        fullMarks: data.fullMarks,
        passMarks: data.passMarks,
      },
    })
  } catch (error) {
    if (isUniqueConstraintError(error)) return { error: t("errors.duplicateSchedule") }
    return { error: t("errors.saveFailed") }
  }

  // Revalidate using the schedule's own examId from the DB, not
  // `data.examId` from the client — a schedule's exam never changes via
  // this action (it's not in the update payload above), so trusting the
  // client value here would only ever invalidate the wrong cache path.
  revalidatePath(`/exams/${existing.examId}`)
  return {}
}

export async function removeExamSchedule(id: string): Promise<ExamResult> {
  const user = await requireRole(...CAN_MANAGE)
  const t = await getTranslations("exams")

  const existing = await prisma.examSchedule.findFirst({
    where: { id, schoolId: user.schoolId },
    include: { _count: { select: { marks: true } } },
  })
  if (!existing) return { error: t("errors.notFound") }
  if (existing._count.marks > 0) return { error: t("errors.cannotRemoveHasMarks") }

  await prisma.examSchedule.delete({ where: { id } })

  revalidatePath(`/exams/${existing.examId}`)
  return {}
}
```

- [ ] **Step 1: Write the server action**

```typescript
"use server"

import { revalidatePath } from "next/cache"
import { getTranslations } from "next-intl/server"
import { Role } from "@prisma/client"
import { prisma } from "@/lib/db/client"
import { requireRole } from "@/lib/auth/dal"
import { isTeacherAssignedToSubjectInSection } from "@/lib/academics/teacher-assignments"
import { saveExamMarksSchema, type SaveExamMarksInput } from "@/lib/validations/exams"

const CAN_ENTER_MARKS: Role[] = [Role.SUPER_ADMIN, Role.SCHOOL_ADMIN, Role.PRINCIPAL, Role.TEACHER]

export type SaveExamMarksResult = { error: string } | { counts: { entered: number; absent: number } }

export async function saveExamMarks(input: SaveExamMarksInput): Promise<SaveExamMarksResult> {
  const user = await requireRole(...CAN_ENTER_MARKS)
  const t = await getTranslations("exams")

  const parsed = saveExamMarksSchema.safeParse(input)
  if (!parsed.success) return { error: t("errors.invalidForm") }
  const data = parsed.data

  // Re-fetch the schedule scoped to this user's school — never trust the
  // examScheduleId just because it appeared in the request. fullMarks is
  // read from here (not from the client) for the range check below.
  const schedule = await prisma.examSchedule.findFirst({
    where: { id: data.examScheduleId, schoolId: user.schoolId },
    include: { exam: { select: { academicYearId: true } } },
  })
  if (!schedule) return { error: t("errors.invalidSelection") }

  const section = await prisma.section.findFirst({
    where: { id: data.sectionId, classId: schedule.classId, class: { schoolId: user.schoolId } },
  })
  if (!section) return { error: t("errors.invalidSelection") }

  // The Phase 4 security fix, extended to subject granularity: a TEACHER
  // may only enter marks for a class+section+subject they have a matching
  // TeacherAssignment for. Admin/Principal are exempt.
  if (user.role === Role.TEACHER) {
    const isAssigned = await isTeacherAssignedToSubjectInSection(
      user.userId,
      schedule.classId,
      data.sectionId,
      schedule.subjectId
    )
    if (!isAssigned) return { error: t("errors.notAssigned") }
  }

  const validStudents = await prisma.student.findMany({
    where: {
      schoolId: user.schoolId,
      classId: schedule.classId,
      sectionId: data.sectionId,
      academicYearId: schedule.exam.academicYearId,
      status: "ACTIVE",
    },
    select: { id: true },
  })
  const validStudentIds = new Set(validStudents.map((student) => student.id))
  if (data.entries.some((entry) => !validStudentIds.has(entry.studentId))) {
    return { error: t("errors.invalidStudents") }
  }

  const hasOutOfRangeMarks = data.entries.some(
    (entry) => !entry.isAbsent && entry.marks !== null && (entry.marks < 0 || entry.marks > schedule.fullMarks)
  )
  if (hasOutOfRangeMarks) return { error: t("errors.marksOutOfRange") }

  try {
    await prisma.$transaction(
      data.entries.map((entry) =>
        prisma.examMark.upsert({
          where: {
            examScheduleId_studentId: { examScheduleId: data.examScheduleId, studentId: entry.studentId },
          },
          update: {
            marks: entry.isAbsent ? null : entry.marks,
            isAbsent: entry.isAbsent,
            enteredById: user.userId,
          },
          create: {
            schoolId: user.schoolId,
            examScheduleId: data.examScheduleId,
            studentId: entry.studentId,
            marks: entry.isAbsent ? null : entry.marks,
            isAbsent: entry.isAbsent,
            enteredById: user.userId,
          },
        })
      )
    )
  } catch {
    return { error: t("errors.saveMarksFailed") }
  }

  revalidatePath(`/exams/${schedule.examId}/marks`)
  revalidatePath(`/exams/${schedule.examId}`)

  const counts = {
    entered: data.entries.filter((entry) => !entry.isAbsent).length,
    absent: data.entries.filter((entry) => entry.isAbsent).length,
  }
  return { counts }
}
```

```typescript
"use client"

import { useRef } from "react"
import { usePathname, useRouter, useSearchParams } from "next/navigation"
import { useTranslations } from "next-intl"
import { Field, FieldLabel } from "@/components/ui/field"
import { NativeSelect, NativeSelectOption } from "@/components/ui/native-select"

type ClassOption = { id: string; name: string }
type SectionOption = { id: string; classId: string; name: string }
type ScheduleOption = { id: string; classId: string; subjectId: string; subjectName: string }

export function MarksSelector({
  classes,
  sections,
  schedules,

  classes: ClassOption[]
  sections: SectionOption[]

function MarksSelectorInner({
  classes,
  sections,
  schedules,
}: {
  classes: ClassOption[]
  sections: SectionOption[]
  schedules: ScheduleOption[]
}) {
  const t = useTranslations("exams")
  const router = useRouter()
  const pathname = usePathname()
  const searchParams = useSearchParams()
  const formRef = useRef<HTMLFormElement>(null)

  const currentClassId = searchParams.get("classId") ?? classes[0]?.id ?? ""
  const availableSections = sections.filter((section) => section.classId === currentClassId)
  const currentSectionId = searchParams.get("sectionId") ?? availableSections[0]?.id ?? ""
  const availableSchedules = schedules.filter((schedule) => schedule.classId === currentClassId)
  const currentScheduleId = searchParams.get("scheduleId") ?? availableSchedules[0]?.id ?? ""

  function submit(overrides: Record<string, string> = {}) {
    const params = new URLSearchParams()
    const formData = new FormData(formRef.current!)

    for (const [key, value] of formData.entries()) {
      if (typeof value === "string" && value) params.set(key, value)
    }
    for (const [key, value] of Object.entries(overrides)) {
      if (value) params.set(key, value)
      else params.delete(key)
    }

    router.push(`${pathname}?${params.toString()}`)
  }

  return (
    <form ref={formRef} className="flex flex-col gap-3 sm:flex-row sm:flex-wrap sm:items-end">
      <Field className="sm:w-48">
        <FieldLabel htmlFor="marks-class">{t("fields.class")}</FieldLabel>
        <NativeSelect
          id="marks-class"
          name="classId"
          defaultValue={currentClassId}
          onChange={(event) => {
            const nextClassId = event.target.value
            const firstSection = sections.find((section) => section.classId === nextClassId)
            const firstSchedule = schedules.find((schedule) => schedule.classId === nextClassId)
            submit({ classId: nextClassId, sectionId: firstSection?.id ?? "", scheduleId: firstSchedule?.id ?? "" })
          }}
        >
          {classes.map((klass) => (
            <NativeSelectOption key={klass.id} value={klass.id}>
              {klass.name}
            </NativeSelectOption>
          ))}
        </NativeSelect>
      </Field>

      <Field className="sm:w-40">
        <FieldLabel htmlFor="marks-section">{t("fields.section")}</FieldLabel>
        <NativeSelect
          id="marks-section"
          name="sectionId"
          defaultValue={currentSectionId}
          onChange={(event) => submit({ sectionId: event.target.value })}
        >
          {availableSections.map((section) => (
            <NativeSelectOption key={section.id} value={section.id}>
              {section.name}
            </NativeSelectOption>
          ))}
        </NativeSelect>

  )
```

```typescript
"use client"

import { useMemo, useState, useTransition } from "react"
import { useTranslations } from "next-intl"
import { Search, Users } from "lucide-react"
import { saveExamMarks } from "@/actions/exams/exam-marks"
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"
import { Checkbox } from "@/components/ui/checkbox"
import { Alert, AlertDescription } from "@/components/ui/alert"
import { EmptyState } from "@/components/shared/empty-state"
import { toast } from "@/components/ui/toast"

export type MarksStudent = { id: string; name: string; roll: number }
export type MarksEntry = { marks: string; isAbsent: boolean }

export function MarksSheet({
  examScheduleId,
  sectionId,
  fullMarks,
  students,
  initialEntries,
}: {
  examScheduleId: string
  sectionId: string
  fullMarks: number
  students: MarksStudent[]
  initialEntries: Record<string, { marks: number | null; isAbsent: boolean }>
}) {
  const t = useTranslations("exams")
  const [isPending, startTransition] = useTransition()
  const [search, setSearch] = useState("")
  const [entries, setEntries] = useState<Record<string, MarksEntry>>(() => {
    const initial: Record<string, MarksEntry> = {}
    for (const student of students) {
      const existing = initialEntries[student.id]
      initial[student.id] = {
        marks: existing?.marks != null ? String(existing.marks) : "",
        isAbsent: existing?.isAbsent ?? false,
      }
    }
    return initial
  })
  const [error, setError] = useState<string | null>(null)

  const visibleStudents = useMemo(() => {
    if (!search.trim()) return students
    const query = search.trim().toLowerCase()
    return students.filter(
      (student) => student.name.toLowerCase().includes(query) || String(student.roll).includes(query)
    )
  }, [students, search])

  function updateEntry(studentId: string, patch: Partial<MarksEntry>) {
    setEntries((prev) => ({ ...prev, [studentId]: { ...prev[studentId], ...patch } }))
  }

  function markAllAbsent() {
    setEntries(() => {
      const next: Record<string, MarksEntry> = {}
      for (const student of students) next[student.id] = { marks: "", isAbsent: true }
      return next
    })
  }

  function onSave() {
    setError(null)
    startTransition(async () => {
      const result = await saveExamMarks({
        examScheduleId,
        sectionId,
        entries: students.map((student) => {
          const entry = entries[student.id]
          return {
            studentId: student.id,
            isAbsent: entry.isAbsent,
            marks: entry.isAbsent || entry.marks === "" ? null : Number(entry.marks),
          }
        }),
      })

      if ("error" in result) {
        setError(result.error)
        return
      }

      toast.add({ title: t("success.marksSaved"), type: "success" })
    })
  }

  if (students.length === 0) {
    return <EmptyState icon={Users} title={t("marks.noStudents")} />
  }

  return (
    <div className="space-y-4">
      {error && (
        <Alert variant="destructive">
          <AlertDescription>{error}</AlertDescription>
        </Alert>
      )}

      <div className="flex flex-col gap-3 sm:flex-row sm:items-center sm:justify-between">
        <div className="relative sm:w-64">
          <Search className="pointer-events-none absolute top-1/2 left-2.5 size-4 -translate-y-1/2 text-muted-foreground" />
          <Input
            value={search}
            onChange={(event) => setSearch(event.target.value)}
            placeholder={t("marks.searchPlaceholder")}
            aria-label={t("marks.searchPlaceholder")}
            className="pl-8"
          />
        </div>
        <Button type="button" variant="outline" onClick={markAllAbsent}>
          {t("actions.markAllAbsent")}
        </Button>
      </div>

      <div className="divide-y rounded-lg border">
        {visibleStudents.map((student) => {
          const entry = entries[student.id]
          return (
            <div
              key={student.id}
              className="flex flex-col gap-2 p-3 sm:flex-row sm:items-center sm:justify-between"
            >
              <div className="flex items-center gap-3">
                <span className="w-7 shrink-0 text-sm text-muted-foreground">{student.roll}</span>
                <span className="font-medium">{student.name}</span>
              </div>
              <div className="flex items-center gap-3">
                <Input
                  type="number"
                  min={0}
                  max={fullMarks}
                  className="w-24"
                  disabled={entry.isAbsent}
                  value={entry.marks}
                  onChange={(event) => updateEntry(student.id, { marks: event.target.value })}
                  aria-label={t("fields.marks")}
                />
                <label className="flex items-center gap-2 text-sm">
                  <Checkbox
                    checked={entry.isAbsent}
                    onCheckedChange={(checked) =>
                      updateEntry(student.id, { isAbsent: checked === true, marks: checked === true ? "" : entry.marks })
                    }
                  />
                  {t("fields.absent")}
                </label>
              </div>
            </div>
          )
        })}
      </div>

      <div className="flex justify-end">
        <Button type="button" onClick={onSave} disabled={isPending}>
          {isPending ? t("actions.saving") : t("actions.saveMarks")}
        </Button>
      </div>
    </div>
  )
}
```

```typescript
import { notFound } from "next/navigation"
import { getTranslations } from "next-intl/server"
import { Role } from "@prisma/client"
import { requireRole } from "@/lib/auth/dal"
import { prisma } from "@/lib/db/client"
import { getTeacherAssignmentTriples } from "@/lib/academics/teacher-assignments"
import { getScheduleCompletion } from "@/lib/exams/completion"
import { PageHeader } from "@/components/shared/page-header"
import { EmptyState } from "@/components/shared/empty-state"
import { CompletionSummary } from "@/components/exams/completion-summary"
import { MarksSelector } from "@/components/exams/marks-selector"
import { MarksSheet } from "@/components/exams/marks-sheet"
import { CalendarX } from "lucide-react"

const ADMIN_ROLES: Role[] = [Role.SUPER_ADMIN, Role.SCHOOL_ADMIN, Role.PRINCIPAL]
const CAN_ENTER_MARKS: Role[] = [...ADMIN_ROLES, Role.TEACHER]

export default async function ExamMarksPage({
  params,
  searchParams,
}: {
  params: Promise<{ examId: string }>
  searchParams: Promise<{ [key: string]: string | string[] | undefined }>
}) {
  const user = await requireRole(...CAN_ENTER_MARKS)
  const t = await getTranslations("exams")
  const { examId } = await params
  const urlParams = await searchParams

  const exam = await prisma.exam.findFirst({ where: { id: examId, schoolId: user.schoolId } })
  if (!exam) notFound()

  const allSchedules = await prisma.examSchedule.findMany({
    where: { examId },
    include: { subject: true },
  })
  const allSections = await prisma.section.findMany({
    where: { class: { schoolId: user.schoolId } },
    select: { id: true, classId: true, name: true },
  })
  const allClasses = await prisma.class.findMany({
    where: { schoolId: user.schoolId, isActive: true },
    orderBy: { order: "asc" },
  })

  // Build the role-scoped option lists server-side, then re-validate every
  // URL param against them below — the same defense-in-depth pattern as
  // attendance/page.tsx (Phase 4's security fix), extended with a subject
  // dimension since marks entry is subject-specific.
  let classes = allClasses.filter((klass) => allSchedules.some((schedule) => schedule.classId === klass.id))
  let sections = allSections
  let schedules = allSchedules.map((schedule) => ({
    id: schedule.id,
    classId: schedule.classId,
    subjectId: schedule.subjectId,
    subjectName: schedule.subject.name,
  }))

  if (user.role === Role.TEACHER) {
    const triples = await getTeacherAssignmentTriples(user.userId)
    const assignedClassIds = new Set(triples.map((triple) => triple.classId))
    const assignedSectionIds = new Set(triples.map((triple) => triple.sectionId))
    const assignedClassSubject = new Set(triples.map((triple) => `${triple.classId}:${triple.subjectId}`))

    classes = classes.filter((klass) => assignedClassIds.has(klass.id))
    sections = allSections.filter((section) => assignedSectionIds.has(section.id))
    schedules = schedules.filter((schedule) => assignedClassSubject.has(`${schedule.classId}:${schedule.subjectId}`))
  }

  let classId = typeof urlParams.classId === "string" ? urlParams.classId : (classes[0]?.id ?? "")
  if (!classes.some((klass) => klass.id === classId)) classId = classes[0]?.id ?? ""

  let sectionId =
    typeof urlParams.sectionId === "string"
      ? urlParams.sectionId
      : (sections.find((section) => section.classId === classId)?.id ?? "")
  if (!sections.some((section) => section.id === sectionId && section.classId === classId)) {
    sectionId = sections.find((section) => section.classId === classId)?.id ?? ""
  }

  const schedulesForClass = schedules.filter((schedule) => schedule.classId === classId)
  let scheduleId = typeof urlParams.scheduleId === "string" ? urlParams.scheduleId : (schedulesForClass[0]?.id ?? "")
  if (!schedulesForClass.some((schedule) => schedule.id === scheduleId)) {
    scheduleId = schedulesForClass[0]?.id ?? ""
  }

  const showSheet = Boolean(classId && sectionId && scheduleId)
  const selectedSchedule = showSheet ? allSchedules.find((schedule) => schedule.id === scheduleId) : undefined

  const students = showSheet
    ? await prisma.student.findMany({
        where: {
          schoolId: user.schoolId,
          classId,
          sectionId,
          academicYearId: exam.academicYearId,
          status: "ACTIVE",
        },
        orderBy: { roll: "asc" },
        select: { id: true, name: true, roll: true },
      })
    : []

  const existingMarks = showSheet
    ? await prisma.examMark.findMany({
        where: { examScheduleId: scheduleId, student: { sectionId } },
        select: { studentId: true, marks: true, isAbsent: true },
      })
    : []
  const initialEntries = Object.fromEntries(
    existingMarks.map((mark) => [mark.studentId, { marks: mark.marks, isAbsent: mark.isAbsent }])
  )

  const completion = showSheet
    ? await getScheduleCompletion({ scheduleId, schoolId: user.schoolId, sectionId })
    : null

  const isTeacherWithNoAssignments = user.role === Role.TEACHER && classes.length === 0

  return (
    <div className="space-y-6">
      <PageHeader title={t("detail.enterMarks")} description={exam.name} />

      {classes.length === 0 ? (
        <EmptyState
          icon={CalendarX}
          title={isTeacherWithNoAssignments ? t("marks.noAssignments") : t("marks.noSchedules")}
        />
      ) : (
        <>
          <MarksSelector classes={classes} sections={sections} schedules={schedules} />
          {showSheet && completion && <CompletionSummary {...completion} />}
          {showSheet && selectedSchedule ? (
            <MarksSheet
              key={`${classId}-${sectionId}-${scheduleId}`}
              examScheduleId={scheduleId}
              sectionId={sectionId}
              fullMarks={selectedSchedule.fullMarks}
              students={students}
              initialEntries={initialEntries}
            />
          ) : (
            <EmptyState icon={CalendarX} title={t("marks.selectPrompt")} />
          )}
        </>
      )}
    </div>
  )
}
```

```typescript
import { getTranslations } from "next-intl/server"
import { ClipboardList } from "lucide-react"
import { prisma } from "@/lib/db/client"
import { EmptyState } from "@/components/shared/empty-state"
import { Card, CardContent, CardHeader, CardTitle } from "@/components/ui/card"
import { Badge } from "@/components/ui/badge"
import { Table, TableHeader, TableBody, TableRow, TableHead, TableCell } from "@/components/ui/table"

export async function ResultsTab({ studentId }: { studentId: string }) {
  const t = await getTranslations("exams")

  const marks = await prisma.examMark.findMany({
    where: { studentId },
    include: { examSchedule: { include: { exam: true, subject: true } } },
    orderBy: [{ examSchedule: { exam: { startDate: "desc" } } }, { examSchedule: { subject: { name: "asc" } } }],
  })

  if (marks.length === 0) {
    return <EmptyState icon={ClipboardList} title={t("results.empty")} />
  }

  const groups: { examId: string; examName: string; rows: typeof marks }[] = []
  for (const mark of marks) {
    const examId = mark.examSchedule.examId
    let group = groups.find((candidate) => candidate.examId === examId)
    if (!group) {
      group = { examId, examName: mark.examSchedule.exam.name, rows: [] }
      groups.push(group)
    }
    group.rows.push(mark)
  }

  return (
    <div className="space-y-4">
      {groups.map((group) => (
        <Card key={group.examId}>
          <CardHeader>
            <CardTitle>{group.examName}</CardTitle>
          </CardHeader>
          <CardContent>
            <Table>
              <TableHeader>
                <TableRow>
                  <TableHead>{t("fields.subject")}</TableHead>
                  <TableHead>{t("results.fullMarks")}</TableHead>
                  <TableHead>{t("results.passMarks")}</TableHead>
                  <TableHead>{t("results.marks")}</TableHead>
                </TableRow>
              </TableHeader>
              <TableBody>
                {group.rows.map((mark) => (
                  <TableRow key={mark.id}>
                    <TableCell>{mark.examSchedule.subject.name}</TableCell>
                    <TableCell>{mark.examSchedule.fullMarks}</TableCell>
                    <TableCell>{mark.examSchedule.passMarks}</TableCell>
                    <TableCell>
                      {mark.isAbsent ? <Badge variant="destructive">{t("results.absent")}</Badge> : mark.marks}
                    </TableCell>
                  </TableRow>
                ))}
              </TableBody>
            </Table>
          </CardContent>
        </Card>
      ))}
    </div>
  )
}
```

- [ ] **Step 3: Write the verification script**

Create `e2e/phase5-exams.mjs`:

```javascript
import { chromium } from "playwright"
import { PrismaPg } from "@prisma/adapter-pg"
import { PrismaClient } from "@prisma/client"

const BASE_URL = process.env.BASE_URL ?? "http://localhost:3000"
const PASSWORD = "Passw0rd!"

const adapter = new PrismaPg({ connectionString: process.env.DATABASE_URL })
const prisma = new PrismaClient({ adapter })

const results = []
function record(name, pass, detail = "") {
  results.push({ name, pass, detail })
  console.log(`${pass ? "PASS" : "FAIL"} - ${name}${detail ? ` (${detail})` : ""}`)
}

async function setupFixtures() {
  const school = await prisma.school.findUniqueOrThrow({ where: { id: "seed-school" } })
  const class7 = await prisma.class.findFirstOrThrow({ where: { schoolId: school.id, name: "Class 7" } })
  const class8 = await prisma.class.findFirstOrThrow({ where: { schoolId: school.id, name: "Class 8" } })
  const section7A = await prisma.section.findFirstOrThrow({ where: { classId: class7.id, name: "A" } })
  const section8A = await prisma.section.findFirstOrThrow({ where: { classId: class8.id, name: "A" } })
  const section7B = await prisma.section.upsert({
    where: { classId_name: { classId: class7.id, name: "B" } },
    update: {},
    create: { classId: class7.id, name: "B" },
  })

  const math = await prisma.subject.upsert({
    where: { schoolId_code: { schoolId: school.id, code: "MATH" } },
    update: {},
    create: { schoolId: school.id, name: "Mathematics", code: "MATH" },
  })
  const english = await prisma.subject.upsert({
    where: { schoolId_code: { schoolId: school.id, code: "ENG" } },
    update: {},
    create: { schoolId: school.id, name: "English", code: "ENG" },
  })

  for (const classId of [class7.id, class8.id]) {
    for (const subjectId of [math.id, english.id]) {
      await prisma.classSubject.upsert({
        where: { classId_subjectId: { classId, subjectId } },
        update: {},
        create: { classId, subjectId },
      })
    }
  }

  const teacher = await prisma.user.findUniqueOrThrow({ where: { email: "teacher@benwil.test" } })
  await prisma.teacherAssignment.upsert({
    where: {
      teacherId_classId_sectionId_subjectId: {
        teacherId: teacher.id,
        classId: class7.id,
        sectionId: section7A.id,
        subjectId: math.id,
      },
    },
    update: {},
    create: { schoolId: school.id, teacherId: teacher.id, classId: class7.id, sectionId: section7A.id, subjectId: math.id },
  })

  const academicYear = await prisma.academicYear.findFirstOrThrow({ where: { schoolId: school.id, name: "2026" } })

  // At least one active student in Class 7 / Section A so the marks sheet
  // has a real row to enter (skip creation if one already exists).
  const existingStudent = await prisma.student.findFirst({
    where: { schoolId: school.id, classId: class7.id, sectionId: section7A.id, academicYearId: academicYear.id },
  })
  if (!existingStudent) {
    await prisma.student.create({
      data: {
        schoolId: school.id,
        studentUid: "E2E-PHASE5-001",
        admissionNumber: "E2E-PHASE5-001",
        name: "Phase5 Test Student",
        dateOfBirth: new Date("2015-01-01"),
        gender: "MALE",
        academicYearId: academicYear.id,
        classId: class7.id,
        sectionId: section7A.id,
        roll: 999,
      },
    })
  }

  return { class7, class8, section7A, section7B, section8A, math, english, academicYear }
}

async function login(page, email) {
  await page.goto(`${BASE_URL}/login`)
  await page.fill('input[name="email"]', email)
  await page.fill('input[name="password"]', PASSWORD)
  await page.click('button[type="submit"]')
  await page.waitForURL(`${BASE_URL}/dashboard`)
}

// Each role below gets its own `browser.newPage()` rather than logging out
// and back in on one page — Playwright's newPage() creates an isolated
// browser context (separate cookies) per call, which is a cleaner way to
// simulate distinct logged-in users than sharing one page's session.
async function main() {
  const fixtures = await setupFixtures()
  const browser = await chromium.launch()

  // --- Admin flow ---
  const adminPage = await browser.newPage()
  await login(adminPage, "school.admin@benwil.test")

  await adminPage.goto(`${BASE_URL}/exams/types`)
  await adminPage.click("text=Add Exam Type")
  await adminPage.fill("#exam-type-name", "E2E Class Test")
  await adminPage.click('button[type="submit"]')
  await adminPage.waitForSelector("text=E2E Class Test")
  record("admin: create exam type", true)

  await adminPage.goto(`${BASE_URL}/exams`)
  await adminPage.click("text=Add Exam")
  await adminPage.fill("#exam-name", "E2E First Term")
  await adminPage.selectOption("#exam-type", { label: "E2E Class Test" })
  await adminPage.fill("#exam-startDate", "2026-01-01")
  await adminPage.fill("#exam-endDate", "2026-01-31")
  await adminPage.click('button[type="submit"]')
  await adminPage.waitForSelector("text=E2E First Term")
  record("admin: create exam", true)

  await adminPage.click("text=E2E First Term")
  await adminPage.waitForURL(/\/exams\/[^/]+$/)
  const examUrl = adminPage.url()
  const examId = examUrl.split("/").pop()

  await adminPage.click("text=Add Subject")
  await adminPage.selectOption("#schedule-class", { label: "Class 7" })
  await adminPage.selectOption("#schedule-subject", { label: "Mathematics" })
  await adminPage.fill("#schedule-examDate", "2026-01-10")
  await adminPage.fill("#schedule-fullMarks", "100")
  await adminPage.fill("#schedule-passMarks", "33")
  await adminPage.click('button[type="submit"]')
  await adminPage.waitForSelector("text=Mathematics")
  record("admin: create exam schedule", true)

  // Duplicate schedule rejection
  await adminPage.click("text=Add Subject")
  await adminPage.selectOption("#schedule-class", { label: "Class 7" })
  await adminPage.selectOption("#schedule-subject", { label: "Mathematics" })
  await adminPage.fill("#schedule-examDate", "2026-01-11")
  await adminPage.fill("#schedule-fullMarks", "100")
  await adminPage.fill("#schedule-passMarks", "33")
  await adminPage.click('button[type="submit"]')
  const duplicateError = await adminPage.locator('[role="alert"]').first().isVisible().catch(() => false)
  record("admin: duplicate schedule rejected", duplicateError)
  await adminPage.keyboard.press("Escape")

  await adminPage.goto(`${BASE_URL}/exams/${examId}/marks?classId=${fixtures.class7.id}&sectionId=${fixtures.section7A.id}`)
  const marksInputs = adminPage.locator('input[type="number"]')
  const inputCount = await marksInputs.count()
  if (inputCount > 0) {
    await marksInputs.first().fill("85")
    await adminPage.click("text=Save Marks")
    await adminPage.waitForSelector("text=Marks saved successfully.")
    record("admin: enter marks", true)
  } else {
    record("admin: enter marks", false, "no student rows rendered")
  }

  await adminPage.close()

  // --- Teacher flow ---
  const teacherPage = await browser.newPage()
  await login(teacherPage, "teacher@benwil.test")

  await teacherPage.goto(`${BASE_URL}/exams/${examId}/marks?classId=${fixtures.class7.id}&sectionId=${fixtures.section7A.id}`)
  const teacherCanSeeMath = await teacherPage.locator("text=Mathematics").first().isVisible().catch(() => false)
  record("teacher: can access assigned Class 7A Mathematics", teacherCanSeeMath)

  // Attempt Class 7B (unassigned section) via URL manipulation. The page
  // re-validates the sectionId query param against the teacher's own
  // assigned sections (src/app/(dashboard)/exams/[examId]/marks/page.tsx)
  // and falls back to an assigned one when it doesn't match — so the
  // rendered <select name="sectionId"> should never resolve to 7B's id.
  await teacherPage.goto(`${BASE_URL}/exams/${examId}/marks?classId=${fixtures.class7.id}&sectionId=${fixtures.section7B.id}`)
  const resolvedSectionId = await teacherPage
    .locator('select[name="sectionId"]')
    .inputValue()
    .catch(() => null)
  record("teacher: cannot force Class 7B via URL param (server re-validates)", resolvedSectionId !== fixtures.section7B.id)

  // Attempt Class 8 entirely (teacher has zero assignments there). Same
  // re-validation applies to classId: the resolved <select name="classId">
  // should never resolve to Class 8's id.
  await teacherPage.goto(`${BASE_URL}/exams/${examId}/marks?classId=${fixtures.class8.id}&sectionId=${fixtures.section8A.id}`)
  const resolvedClassId = await teacherPage
    .locator('select[name="classId"]')
    .inputValue()
    .catch(() => null)
  record("teacher: cannot access Class 8 via URL param", resolvedClassId !== fixtures.class8.id)

  await teacherPage.goto(`${BASE_URL}/exams/types`)
  await teacherPage.waitForURL(`${BASE_URL}/unauthorized`)
  record("teacher: /exams/types is forbidden (unauthorized redirect)", true)

  await teacherPage.close()

  // --- Cross-school check: another school's exam id must 404 ---
  const otherSchool = await prisma.school.upsert({
    where: { id: "e2e-other-school" },
    update: {},
    create: { id: "e2e-other-school", name: "E2E Other School" },
  })
  const otherYear = await prisma.academicYear.upsert({
    where: { schoolId_name: { schoolId: otherSchool.id, name: "2026" } },
    update: {},
    create: { schoolId: otherSchool.id, name: "2026", isActive: true },
  })
  const otherType = await prisma.examType.upsert({
    where: { schoolId_name: { schoolId: otherSchool.id, name: "Other School Exam Type" } },
    update: {},
    create: { schoolId: otherSchool.id, name: "Other School Exam Type" },
  })
  const otherExam = await prisma.exam.create({
    data: {
      schoolId: otherSchool.id,
      academicYearId: otherYear.id,
      examTypeId: otherType.id,
      name: "Other School Exam",
      startDate: new Date("2026-01-01"),
      endDate: new Date("2026-01-31"),
    },
  })

  const adminPage2 = await browser.newPage()
  await login(adminPage2, "school.admin@benwil.test")
  const response = await adminPage2.goto(`${BASE_URL}/exams/${otherExam.id}`)
  record("cross-school exam id returns 404", response?.status() === 404)
  await adminPage2.close()

  // --- Mobile viewport check (~390px) ---
  const mobilePage = await browser.newPage({ viewport: { width: 390, height: 844 } })
  await login(mobilePage, "school.admin@benwil.test")
  for (const path of [`/exams`, `/exams/${examId}`, `/exams/${examId}/marks`]) {
    await mobilePage.goto(`${BASE_URL}${path}`)
    const hasOverflow = await mobilePage.evaluate(() => document.documentElement.scrollWidth > document.documentElement.clientWidth + 1)
    record(`mobile (390px): no horizontal overflow on ${path}`, !hasOverflow)
  }
  await mobilePage.close()

  await browser.close()
  await prisma.$disconnect()

  const failed = results.filter((result) => !result.pass)
  console.log(`\n${results.length - failed.length}/${results.length} checks passed.`)
  if (failed.length > 0) {
    console.log("Failed checks:", failed.map((result) => result.name).join(", "))
    process.exitCode = 1
  }
}

main().catch((error) => {
  console.error(error)
  process.exitCode = 1
})
```

- [ ] **Step 5: Note the honest scope of "direct server action" verification**

This script verifies unauthorized access *through the browsable UI* (URL/query-param manipulation), which is the realistic attack surface for a Next.js Server Action (there is no separate REST endpoint to hit directly — the action is only reachable through the page that references it). "Direct server action call is rejected" for the disallowed combinations is additionally verified by code inspection of `src/actions/exams/exam-marks.ts` (Task 8): `requireRole` re-derives identity from the session cookie, and `isTeacherAssignedToSubjectInSection` is re-checked against the database on every call regardless of what the client submitted — the same guarantee `save-attendance.ts` already provides for Phase 4, which this action mirrors exactly. Record this distinction in the final report (next task) rather than overclaiming a synthetic raw-HTTP forged action call was executed.
